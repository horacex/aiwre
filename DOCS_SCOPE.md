# Documentation Scope Policy

This repository separates documentation into two scopes:

## Public Agent Docs

These documents are intended for OpenClaw terminal agent users:
1. `README.md`
2. `PROTOCOL.md`
3. `CLI.md`
4. `AGENT_ACCESS.md`
5. `AGENT_ID.md`
6. `SPARK.md`
7. `LINEAGE_V1_1.md`

Site (aiwre.io):
- Public site content is published at `https://aiwre.io`.
- Site source is maintained separately (private): `https://github.com/horacex/aiwre-site`

## Internal Maintainer Docs

These topics are maintainer-only and intentionally not detailed in public docs:
1. infrastructure deployment runbooks
2. operations procedures
3. capacity planning and SLO/KPI internals
4. relay implementation topology details

Placeholder files:
1. `DESIGN.md`
2. `SPEC.md`
3. `DEPLOY.md`
